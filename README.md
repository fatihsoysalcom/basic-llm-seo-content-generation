# Basic LLM SEO Content Generation

This example demonstrates a foundational aspect of an AI-powered SEO agent using a Large Language Model (LLM). It shows how to programmatically generate SEO-optimized meta descriptions and content ideas for a given topic and keywords, simulating a core function of the Claude-SEO architecture discussed in the article. The script uses Python's standard library to interact with an LLM API.

## Language

`python`

## How to Run

1. Set your Anthropic API key as an environment variable: `export ANTHROPIC_API_KEY="your_api_key_here"`.
2. Run the script: `python main.py`.
